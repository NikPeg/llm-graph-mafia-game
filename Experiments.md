# Проект: Влияние RAG на LLM-агентов в «Мафии»

## 1. Концепция эксперимента

Наш план экспериментов сфокусирован на сравнении двух моделей от Qwen:
*   **"Давид" (D):** Модель класса 8B.
*   **"Голиаф" (G):** Модель класса 32B.

**Определение RAG-усиления (+RAG):**
Эксперимент будет проходить в два этапа.
1.  **Этап 1: Поиск оптимального RAG-компонента.** Сначала мы проведем серию тестов, чтобы определить, какой из RAG-компонентов (`Граф истории`, `Граф текущего раунда`, `Коммуникационный граф`, `Автоматические саммари`, `Аналитические подсказки`) дает наибольший прирост производительности.
2.  **Этап 2: Основная сетка экспериментов.** Термин **+RAG** в приведенной ниже таблице означает использование **одного, самого эффективного компонента**, выявленного на первом этапе.

Цель — систематически измерить, как размер модели и лучшее RAG-усиление влияют на исход игры, и проверить ключевую гипотезу: **может ли "Давид" с RAG победить "Голиафа"?**

## 2. План экспериментов (Этап 2)

Ниже представлен полный список из 16 экспериментов, необходимых для всесторонней проверки гипотез с использованием **наилучшего** RAG-компонента.

| ID Эксперимента | Мафия | Мирные | Краткое описание | Ключевая цель / Гипотеза |
| :--- | :--- | :--- | :--- | :--- |
| **D-vs-D** | 8B | 8B | Базовый тест для 8B моделей. | Установить **baseline winrate** для "слабых" моделей. |
| **D_RAG-vs-D_RAG** | 8B+RAG | 8B+RAG | Симметричный тест с RAG для 8B. | Оценить чистый **эффект от RAG** на 8B моделях. |
| **D-vs-D_RAG** | 8B | 8B+RAG | Асимметричный тест: только мирные усилены. | Проверить **преимущество RAG** в атаке (мирные) против защиты. |
| **D_RAG-vs-D** | 8B+RAG | 8B | Асимметричный тест: только мафия усилена. | Проверить **преимущество RAG** в обмане (мафия) против анализа. |
| **G-vs-G** | 32B | 32B | Базовый тест для 32B моделей. | Установить **baseline winrate** для "сильных" моделей. |
| **G_RAG-vs-G_RAG** | 32B+RAG | 32B+RAG | Симметричный тест с RAG для 32B. | Оценить чистый **эффект от RAG** на 32B моделях. |
| **G-vs-G_RAG** | 32B | 32B+RAG | Асимметричный тест: только мирные усилены. | Проверить **преимущество RAG** в игре равных по силе. |
| **G_RAG-vs-G** | 32B+RAG | 32B | Асимметричный тест: только мафия усилена. | Проверить **преимущество RAG** в игре равных по силе. |
| **G-vs-D** | 32B | 8B | Классический "Голиаф против Давида". | Установить **baseline разницы в силе** между моделями. |
| **G-vs-D_RAG** | 32B | 8B+RAG | **Ключевой тест:** сильная мафия против усиленных мирных. | **Компенсирует ли RAG разницу в размере модели для мирных?** |
| **G_RAG-vs-D** | 32B+RAG | 8B | "Двойное преимущество": сильная и усиленная мафия. | Оценить **максимальный разрыв в производительности**. |
| **G_RAG-vs-D_RAG** | 32B+RAG | 8B+RAG | Обе стороны усилены, но разный размер. | **Сохраняется ли преимущество в размере**, когда обе модели усилены RAG? |
| **D-vs-G** | 8B | 32B | Обратная ситуация: слабая мафия против сильных мирных. | Установить **обратный baseline** разницы в силе. |
| **D_RAG-vs-G** | 8B+RAG | 32B | **Ключевой тест 2:** усиленная мафия против сильных мирных. | Может ли усиленная "слабая" мафия **эффективно обманывать** "сильных" мирных? |
| **D-vs-G_RAG** | 8B | 32B+RAG | Максимальный разрыв в обратную сторону. | Оценить, насколько беспомощна слабая мафия против сильных и усиленных мирных. |
| **D_RAG-vs-G_RAG** | 8B+RAG | 32B+RAG | Финальное сравнение, обратная ситуация. | Итоговый баланс сил с асимметрией в размере. |

## 3. Метрики для оценки

### Основные метрики для отслеживания

| Метрика | Описание | Зачем нужна |
| :--- | :--- | :--- |
| **Средняя длина игры** | Количество дней (раундов) до завершения партии. | Оценка эффективности стратегий и скорости выявления мафии. |
| **Точность голосований** | % правильных голосов мирных против мафии. | Прямой показатель качества анализа и коллективного рассуждения. |
| **Survival rate мафии** | Среднее количество раундов, которые член мафии выживает. | Оценка качества маскировки мафии и ее способности вводить в заблуждение. |
| **False positive rate** | % мирных, ошибочно казненных по итогам голосования. | Измерение ошибок детекции и склонности к "охоте на ведьм". |
| **Консистентность** | Стабильность winrate и других метрик по батчам игр. | Оценка надежности и воспроизводимости результатов для каждой модели. |

### Аналитические метрики (для анализа результатов)

| Метрика | Описание | Формула для расчета |
| :--- | :--- | :--- |
| **RAG Boost** | Абсолютный прирост winrate от использования RAG. | `WR(с RAG) - WR(без RAG)` |
| **Size Compensation** | Насколько RAG для 8B модели компенсирует разницу в размере. | `WR(8B+RAG) - WR(32B)` |
| **RAG Efficiency** | Сравнение эффективности RAG для моделей разного размера. | `RAG_Boost_8B / RAG_Boost_32B` |

## 4. Общий расчет числа экспериментов

1.  **Этап 1: Определение лучшего RAG-компонента.**
    *   Проводится на наиболее показательной конфигурации `32B (Мафия) vs 8B (Мирные)`.
    *   **Базовый тест** `G-vs-D`: **1 эксперимент**.
    *   **Тестирование каждого из 5 RAG-компонентов** для мирных: **5 экспериментов**.
    *   *Итого на Этапе 1: 1 + 5 = **6 экспериментов.***

2.  **Этап 2: Основная сетка экспериментов.**
    *   Полная сетка, описанная в таблице выше, для тестирования лучшего RAG-компонента.
    *   *Итого на Этапе 2: **16 экспериментов.***

### Итого:

Общее количество уникальных конфигураций для проведения экспериментов: 6 (Этап 1) + 16 (Этап 2) = **22 эксперимента**.
