### План экспериментов: Мафия "Голиаф" против усиленных Мирных "Давидов"

| ID Эксперимента | Дополнительные данные для Мирных (8b) | Цель / Измеряемая гипотеза |
| :--- | :--- | :--- |
| **D-Base (Контроль)** | `Нет` (только raw text) | Установить базовый **winrate** мирных против сильного противника. **Это наш контрольный показатель.** |
| **D-Comms** | **Коммуникационный граф** | Оценить, дает ли знание о социальных связях преимущество мирным. |
| **D-Round** | **Граф текущего раунда** | Измерить влияние тактической информации о событиях последнего раунда на winrate. |
| **D-History** | **Граф истории** | Проверить, насколько сильно помогает полная историческая картина взаимодействий. |
| **D-Summary** | **Автоматические саммари** | Проверить, помогает ли сжатый контекст 8b-модели лучше фокусироваться на главном. |
| **D-Hints** | **Аналитические подскадки** | Оценить эффект от предоставления готовых логических выводов. |
| **D-Full** | **Все улучшения** (Все 3 графа + Саммари + Подсказки) | **Проверка главной гипотезы:** сможет ли команда 8b моделей со всеми улучшениями стабильно **побеждать** команду 40b моделей? |
