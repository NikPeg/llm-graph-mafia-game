# Проект: Влияние графов на LLM-агентов в «Мафии»

## 1. [Текущая работа](https://github.com/NikPeg/llm-graph-mafia-game) (Результаты курса SNA)
- **Гипотеза**: Графовое представление улучшает коллективное рассуждение.
- **Методология**:
  - Форк `llm-mafia-game` с локальными LLM (vllm).
  - Батчи по 80 партий.
  - Логирование в Firebase, веб-дэшборд.
- **Ключевой результат**:
  - `Таблица 1`: Победы мирных граждан.
  - **Вывод**: Глобальный граф с накоплением истории (`Global history`) — самая успешная стратегия (winrate 54-58%).
  - Графы без истории (`Коммуникационный`, `Граф последнего раунда`) малоэффективны.
- **Заключение**: Подход работает и воспроизводим.

## 3. Направления развития проекта

### 3.1. Образовательный продукт (Soft-skills)
- **Концепция**: "Мафия" как тренажер для soft-skills (эмпатия, убеждение, анализ).
- **Идеи для реализации**:
  - Специализированные LLM-модели для оценки действий игроков.
  - Система автоматической обратной связи для развития навыков.
  - "Говорилка": бот для общения с игроками.
- **Аналогия**: [VIBE](onelink.to/vibe-ai) (как пример обратной связи от ИИ по софт-скиллам).

### 3.2. Усиление агентов через RL/MDP 🚀
- **Идея**: Обучать агентов играть оптимальнее через RL.
- **Подход**:
    - **Модель**: Использовать RL-алгоритмы, например, `R2D2`.
    - **Среда**: Текущий симулятор игры.
- **Инфраструктура**:
    - Создать **базу игр** (геймлогов) для тестирования и валидации.
    - Разработать **бенчмарк** для сравнения качества новых агентов и стратегий.

### 3.3. "Умный Давид против глупого Голиафа" 🧠
- **Цель**: Доказать, что маленькая модель (8b) может обыграть большую (32b) за счет более качественной информации.
- **Механизм ("костыли")**: Предоставление маленькой модели структурированной информации, недоступной большой.
    - **Графовые представления**: Коммуникационный граф, граф истории (основа текущей работы).
    - **Краткие саммари**: Автоматические выжимки ключевых событий раунда.
    - **Аналитические подсказки**: Список подозреваемых с аргументами.
- **Практическая польза**: Поиск экономичных и эффективных решений, не требующих гигантских моделей.
